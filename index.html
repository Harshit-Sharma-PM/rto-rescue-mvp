Opportunity map

Four intervention moments

01 · Order created — COD confirmation
Confirm genuine intent. Cancel pre-dispatch only on explicit customer choice or merchant policy.

02 · Before dispatch — address verification
Collect missing flat, landmark or pin details; hold only when required data is invalid.

03 · Before dispatch — prepaid nudge
Offer a voluntary, transparent benefit; preserve COD choice under merchant policy.

04 · NDR raised — WhatsApp + targeted voice
Capture availability/address, submit supported carrier action, track final delivery. Voice for high-risk/high-value COD and WhatsApp non-responders.

Customer choices · downstream states

What happens after a response

Confirm → order remains eligible for normal fulfilment; tag confirmation event.

Edit details → open a correction form; validate pin/address, write approved changes to Shopify, tag event and re-run eligibility before dispatch.

Cancel → show explicit confirmation step; apply merchant cancellation/refund policy; stop dispatch if not fulfilled; report as pre-dispatch cancellation, not shipped-order RTO.

Prepaid delivery issue → no COD-intent prompt; use address correction, delivery-day reminder, delay alert and payment-aware NDR rescue.

Measurement contract

Metrics the product should enforce

North Star

All eligible shipped orders (COD + prepaid) with mature outcomes; RTO shipments ÷ eligible shipped orders.

Leading indicators

COD confirmation outcome vs control; NDR delivery lift vs control; address corrections; time to next action.

Guardrails

Complaints, opt-outs, false cancellations, address errors, duplicate actions, carrier failures and contribution margin.

Six-month mandate

Prove it before scaling it.

Ship pre-dispatch COD confirmation first, pair it with NDR rescue, and use voice for high-risk or WhatsApp-unresponsive orders under controlled tests.

MONTH 01

Diagnose & baseline

Merchant-level cause mix, COD vs prepaid, cost/order, consent, event and API audit.

MONTH 02

COD confirmation

Shopify order webhook, WhatsApp confirm/cancel, retry policy and audit tags.

MONTH 03

Address + NDR MVP

Address correction before dispatch; one-provider NDR ingestion and rescue flows.

MONTH 04

Controlled pilot

Holdout/control, mature outcomes, carrier acknowledgements and reason-level dashboard.

MONTH 05

Targeted voice

Test high-risk/high-value COD and WhatsApp non-responders; compare incremental lift and cost.

MONTH 06

Scale / stop

Scale only if RTO and cost improve, integrations are reliable and guardrails hold.
